## Overview

CeylonDemon is a free UCI chess engine built on the **NARC Engine** codebase —
board representation, move generation and search — by the same author, under
GPLv3. Its evaluator, **Resonance**, is original to CeylonDemon.

## The Resonance evaluator

Conventional NNUE evaluators anchor their feature set on the side to move's own
king: every piece is encoded relative to where *my* king stands. That frame
describes shelter and structure well, and is comparatively blind to what the
position looks like from the attacking side.

Resonance reads every position through two independent feature transformers
that differ only in which king anchors the frame:

- **AEGIS** — bucketed by the perspective side's own king. A defensive frame:
  *how safe and well-structured am I?*
- **LANCE** — bucketed by the opposing king. An offensive frame: *how much
  pressure is on their king?*

Their scalar outputs are combined by a learned per-bucket gate. The interesting
quantity is not the blend but the residual:

```
sigma = |AEGIS − LANCE|
```

Sigma measures how much the two frames disagree. It is large exactly where a
single scalar evaluation is least trustworthy — sharp positions where a
defensive reading and an offensive reading diverge. The search consumes sigma
directly, preserving an extra ply of depth in the high-disagreement tail.

**Geometry.** 7680 features per frame (10 king buckets × 12 piece classes × 64
squares), 320 accumulator lanes per frame per perspective, 8 output buckets
selected by piece count. Inference is integer throughout; there is no floating
point in the forward pass. The network is trained on a 73.2-million-position
self-play corpus generated by the engine itself.

## Board and search

Bitboards with magic sliding attacks, 16-bit moves, pseudo-legal generation with
a king-attack legality test, Zobrist hashing. Search is principal variation
search with a shared transposition table, killers, counter-moves, history with
gravity, continuation and capture history, late move reductions, null-move
pruning with high-depth verification, ProbCut, singular extensions, bounded
check extensions, reverse futility, razoring and quiescence.

Move generation is verified against published perft references:

| Position | Depth | Nodes |
|---|---|---|
| Start position | 5 | 4,865,609 |
| "Kiwipete" | 4 | 4,085,603 |

## Building

Requires GCC 12+ (MSYS2 UCRT64 on Windows). The network is linked into the
executable, so a release is a single self-contained file.

```bash
make                    # x86-64-avx2, portable release default
make ARCH=x86-64-bmi2   # Skylake and later, fast PEXT
make ARCH=native        # tuned to this machine
```

On Windows, `.\build.ps1` does the same and also links the version resource.

## UCI options

| Option | Default | Meaning |
|---|---|---|
| `Hash` | 128 | Transposition table size, MB |
| `Threads` | 1 | Search threads |
| `Move Overhead` | 30 | Milliseconds reserved for GUI/network latency |
| `EvalFile` | `<embedded>` | Load an external `.aa` network instead of the built-in one |

Beyond UCI, `eval` prints the blended score and sigma for the current position
and verifies the incremental accumulator against a full refresh.
